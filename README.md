## 📖 Descripción de los Programas

- **1.asm:** Lee una cadena y avisa si está vacía.
- **2.asm:** Pasa dos valores por la pila y los multiplica en un procedimiento.
- **3.asm:** Muestra en hexadecimal las direcciones de retorno guardadas en la pila al llamar procedimientos anidados.
- **4.asm:** Llama dos veces un procedimiento para mostrar un mensaje.
- **macro.asm:** Usa macros para mostrar mensajes y multiplicar dos números.
